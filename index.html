推荐学习路径

地基 → 引擎 → 渲染 → 角色

  1. GAMES101 · 现代计算机图形学入门

    先把数学语言（向量、矩阵、变换、投影）和图形学主流程（光栅化、着色、几何、光线追踪）打通。 进入课程 →

  2. GAMES104 · 现代游戏引擎：理论、实践与架构

    带着 101 的图形学视角去看引擎：一帧里 CPU/GPU 各做什么，各子系统如何拼起来。 进入课程 →

  3. GAMES202 · 高质量实时渲染

    在 101 的渲染方程基础上，深入阴影、IBL、实时 GI、降噪——3A 画面观感的主要来源。 进入课程 →

  4. GAMES105 · 计算机角色动画基础

    最后补角色：骨骼、蒙皮、动作数据、物理驱动与强化学习，让角色动得可信。 进入课程 →

怎么用这本手册

三步循环

三步循环

  1. 先读每讲的「核心结论速记」建立框架，能在不看公式的情况下复述。
  2. 再看正文与公式；遇到没读懂的地方点开课件原图对照，最后做课后练习自检。
  3. 做项目时把每讲的「常见坑」当排查清单，「UE/Unity 落地」当关键词去查引擎文档。
